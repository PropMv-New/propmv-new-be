## Notes

- Flag overrides are applied on `process.env` for each scenario (same mechanism as `.env.local` at runtime).
- `.env.local` itself is not permanently mutated by this script.
- `skipPersist=true` avoids writing Email collection rows during verification.
- `skipRecipientValidation=true` mirrors trusted system-email callers.
- Templates without an active `.env.local` line still default to enabled unless overridden; this harness forces both states.
